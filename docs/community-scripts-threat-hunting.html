Threat Hunting Tools

Python 3 Community Security Research

Python-based threat hunting toolkits that use the Zero Networks activity API to detect suspicious network behaviors — from arbitrary IOC searches to Remote Monitoring and Management (RMM) software identification.

Python toolkits — not standalone scripts Both tools are structured Python packages, not single-file scripts. Each requires a pip install -r requirements.txt before use and reads the API key from the ZN_API_KEY environment variable.

Prerequisites

RequirementDetails
Python 3.9+Tested on Python 3.9 and higher
ZN_API_KEYSet as an environment variable. A read-only key is sufficient for hunting.
pip dependenciesInstall with pip install -r requirements.txt in each tool's directory
.env fileOptionally create a .env file in the tool directory with ZN_API_KEY=eyJ... for python-dotenv loading

Hunt Any Threat

Python 3Toolkit
🔗 View on GitHub

Overview

A Python library and example scripts for hunting arbitrary threats in Zero Networks network activity data. Provides a ZeroThreatHuntTools class with high-level search methods covering domains, IP addresses, destination ports, and running processes.

Directory Structure

PathDescription
example.pyRunnable examples demonstrating each search method
src/zero_networks/api.pyLow-level Zero Networks REST API wrapper
src/zero_threat_hunt_tools/zero_threat_hunt_tools.pyMain ZeroThreatHuntTools class
tests/pytest test suite with conftest fixtures

ZeroThreatHuntTools Methods

MethodDescription
get_activities_to_domains(domains)Find network activities destined for specified domain names
get_activities_to_destination_ips(ips)Find activities destined for specified IP addresses
get_activities_to_destination_ports(ports)Find activities on specified destination ports
get_activities_to_destination_processes(processes)Find activities from specified source processes

Quick Start

Step 1Install dependencies
$ cd "Segment/Threat Hunting/Hunt Any Threat"
pip install -r requirements.txt
Step 2Set API key and run examples
$ ZN_API_KEY=eyJ... python example.py
Runs all example functions sequentially. Each example demonstrates a different search method with console output showing found activities.
Step 3Use the library in your own scripts
from src.zero_threat_hunt_tools.zero_threat_hunt_tools import ZeroThreatHuntTools

hunter = ZeroThreatHuntTools(api_key="eyJ...")
activities = hunter.get_activities_to_domains(["malicious-domain.com"])
print(f"Found {len(activities)} suspicious connections")
TestsRun the test suite
$ pytest tests/

Hunt For RMMLs

Python 3CLI ToolRMM Detection
🔗 View on GitHub

Overview

A CLI tool that hunts for Remote Monitoring and Management (RMM) software activity in your Zero Networks environment. Uses a community-maintained YAML database of known RMM tool signatures (cloned from GitHub) to detect unauthorized or shadow IT RMM tools.

Directory Structure

PathDescription
hunt.pyMain CLI entry point with argparse
src/git_ops.pyClones/validates the RMM signature database from GitHub
src/rmmdata.pyLoads and parses YAML signature files
src/zn_hunt_ops.pyZero Networks activity search logic
src/zero_networks/api.pyZN REST API wrapper (shared pattern with Hunt Any Threat)
Step 1Install and run
$ cd "Segment/Threat Hunting/Hunt For RMMLs"
pip install -r requirements.txt
ZN_API_KEY=eyJ... python hunt.py --help
Step 2Run a hunt with verbose output
$ ZN_API_KEY=eyJ... python hunt.py -v
Clones the RMM signature database, loads YAML signatures, queries ZN network activity for matching domains/IPs/ports, and reports any hits. Use -vv for debug output or -vvv for trace.
Signature source RMM signatures are automatically cloned from a community-maintained GitHub repository. Ensure the host running the script has outbound HTTPS access to GitHub.
