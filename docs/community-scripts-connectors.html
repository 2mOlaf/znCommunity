Installation and management scripts for the Zero Networks Cloud Connector (Windows) and the Segment Connector lightweight agent (Linux).

install-CloudConnectorAPI.ps1

PowerShell 5.1+Cloud ConnectorWindows
🔗 View on GitHub

Synopsis

Installs or uninstalls the Zero Networks Cloud Connector on Windows. Decodes the provided JWT token to determine the correct installer endpoint, downloads the installer, and executes it with the appropriate arguments.

Parameters

-CloudConnectorFunction

Whether to install or uninstall the Cloud Connector.

Accepted values:install, uninstall
Default:install
-CloudConnectorToken

JWT token from the Zero Networks portal used to authorize the install. Decoded locally to determine the API audience URL.

Required:True (replace placeholder)
-CloudConnectorSource

Identity source environment for the Cloud Connector.

Accepted values:AD, WORKGROUP, AZURE, AZURE_AD, AWS, GCP, IBM, ORACLE, VMWARE, ALIBABA, OVH, LUMEN, DOMAIN-JOINED-MANUALLY-SYNC
Default:AD
-DomainJoinedManuallySync

When present, passes the -domain-joined-manually-sync flag to the installer. Use when the machine is domain-joined but synchronization is managed manually.

Type:Switch

Logs

FileContents
%TEMP%\CloudConnector.logScript execution log
%LOCALAPPDATA%\ZeroNetworks\logs\setup.logInstaller log (if present)
Example 1Install Cloud Connector for Active Directory
PS> .\install-CloudConnectorAPI.ps1 -CloudConnectorToken eyJ... -CloudConnectorSource AD
Example 2Install for Azure AD
PS> .\install-CloudConnectorAPI.ps1 -CloudConnectorToken eyJ... -CloudConnectorSource AZURE_AD
Example 3Uninstall
PS> .\install-CloudConnectorAPI.ps1 -CloudConnectorFunction uninstall -CloudConnectorToken eyJ...

enroll-linux-install-segment-connector.sh

BashLinuxSegment Connector
🔗 View on GitHub

Synopsis

Enrolls a Linux host into the Zero Networks management plane and installs the Segment Connector (lightweight agent). Handles prerequisite checks, package download, and registration token exchange.

Run as root — this script requires sudo or root access to install the Segment Connector service and configure the system.
Example 1Enroll and install
$ sudo bash enroll-linux-install-segment-connector.sh
Follow the prompts to supply your Zero Networks enrollment token. The script validates prerequisites, downloads the Segment Connector package, installs it, and registers the host.

uninstall-linux-segment-connector.sh

BashLinuxUninstall
🔗 View on GitHub

Synopsis

Stops and removes the Zero Networks Segment Connector lightweight agent from a Linux system, including cleaning up service definitions, packages, and configuration files.

Example 1Uninstall the Segment Connector
$ sudo bash uninstall-linux-segment-connector.sh
