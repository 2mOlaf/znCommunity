Settings & API Scripts

PowerShell Community Configuration

Scripts for configuring Zero Networks system settings, auditing Active Directory Group Policy, managing Kerberos tickets, and authenticating to the Zero Networks API.

Add-ZNTrustedInternetAddresses.ps1

PowerShellSystem Settings
🔗 View on GitHub

Synopsis

Reads a list of IP addresses from a file and adds any that are not already present to the Zero Networks Trusted External IPs list in system settings.

Additive only — this script only adds IPs; it does not remove existing entries. The current Trusted External IP list is fetched first and the new IPs are merged before the PUT call.
Example 1Add IPs from a file (interactive prompts)
PS> $apikey = 'eyJ...'
.\Add-ZNTrustedInternetAddresses.ps1
If the API key placeholder is unchanged, the script prompts for it. Then prompts for the path to a text file with one IP address per line. Fetches the current list, merges new entries, and PUTs the updated list back.

Get-ADGPOsWithFWRules.ps1

PowerShellActive DirectoryAudit
🔗 View on GitHub

Synopsis

Enumerates all GPOs in the domain and identifies any that contain Windows Firewall settings (rules, domain profile, private profile, or public profile), excluding the Zero Networks GPOs themselves.

Requirements

RequirementDetails
ActiveDirectory modulePart of RSAT. Import-Module ActiveDirectory
GroupPolicy modulePart of RSAT. Import-Module GroupPolicy
Domain connectivityMust run on a domain-joined machine with access to SYSVOL
Example 1Find non-ZN GPOs with firewall settings
PS> .\Get-ADGPOsWithFWRules.ps1
Checks all GPOs against the four Windows Firewall registry paths. Outputs GPO names that have conflicting firewall settings in red. These GPOs may interfere with Zero Networks enforcement.

purgeKerberosOnHosts.ps1

PowerShellActive DirectoryGPO Refresh
🔗 View on GitHub

Synopsis

Remotely purges Kerberos tickets and forces a Group Policy update on a list of Windows servers. Useful for accelerating ZN agent deployment — the Kerberos ticket contains group membership data that must be refreshed before a GPO change takes effect.

Inputs

FileDescription
hosts.csvSingle-column CSV of server hostnames (one per line, with or without FQDN). Must be in the same directory as the script.

Remote Commands Executed

CommandEffect
klist -li 0x3e4 purgePurges the Network Service Kerberos ticket cache
klist -li 0x3e7 purgePurges the Computer Account Kerberos ticket cache
gpupdate /forceForces immediate Group Policy refresh
Commands run asynchronously in parallel across all hosts using Invoke-Command jobs, improving performance at scale. A log file named YYYY-MM-DD-zn-klist-purge.log is written to the working directory.

sample.ps1

PowerShellAPI Sample
🔗 View on GitHub

Synopsis

A minimal reference script demonstrating how to construct the authentication headers and make a basic API call to the Zero Networks REST API using PowerShell.

Use this as a starting point when building custom integrations. The pattern shown — setting Authorization and content-type headers and calling Invoke-RestMethod — is used consistently across all community scripts.
