Which tool should I use?

I want to…Use
Automate asset management, approve rules, manage labels and groups via the ZN API ZeroNetworks module (PSGallery)
Check environment health, run port tests, or query segment cluster info from a Segment Server ZNTools
Browse segmentedAssets.json with PowerShell queries instead of raw JSON ZNTools BG Asset Browser
Restart or stop/start ZN services on one or all Segment Servers ZNTools — Invoke-ZNServices
Emergency access recovery — portal or Segment Server is down BreakGlass scripts (pre-installed)
Remove Zero Networks ACLs from OT switches during an incident OTBreakGlass.ps1
Add a new command to ZNTools or understand how the module is structured ZNTools Author Guide
Batch-queue assets for learning, manage groups, or audit asset states via the API Asset Management Scripts
Approve proposed rule deletions or update block rules from external data Rules & MFA Scripts
Test connectivity to ZN cloud endpoints or diagnose GPO/admin group issues Troubleshooting Scripts
Export audit logs to CSV or filter WinRM trust server logs by asset ID Segmentation Server Scripts
Hunt for suspicious domain/IP/port/process activity or detect RMM tools Threat Hunting Tools
