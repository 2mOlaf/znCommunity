Add-ClientsToIdentityLearning.ps1

PowerShellIdentity Learning
🔗 View on GitHub

Synopsis

Finds all monitored client assets that are not yet identity-segmented, then queues them for a 30-day identity learning period in batches of 100.

Prerequisites

RequirementDetails
ZeroNetworks moduleAuto-installed via Install-Module ZeroNetworks if not present
API keySet $apiKey in the script

How It Works

  1. Looks up the built-in Clients system group (g:s:*).
  2. Builds a filter for monitored assets that are in the Clients group and have identity protection status 1 (not identity-segmented).
  3. Pages through all matching assets (400 per request).
  4. Batches the asset IDs (100 per call) and POSTs to /assets/identity-actions/queue with a 30-day learning duration.
Example 1Queue all eligible client assets for identity learning
PS> $apiKey = 'eyJ...'
.\Add-ClientsToIdentityLearning.ps1

get-currentSVCAccounts.ps1

PowerShellService Accounts
🔗 View on GitHub

Synopsis

Retrieves service accounts that have logged on within the past $n days and are not yet identity-protected, then optionally queues them for a 30-day identity learning period.

Parameters

-n

Number of days to look back for account activity. Accounts with a lastLogon timestamp older than this value are excluded.

Type:Int
Default:180 days
-APIKey

Zero Networks API key.

Default:<API_KEY> placeholder — must be set
Example 1Find and queue service accounts active in the last 180 days
PS> .\get-currentSVCAccounts.ps1 -APIKey eyJ...
Fetches all service accounts, filters to those with lastLogon within 180 days and protectionState != 3 (not already protected), prints their names, and queues them for identity learning if any are found.
Example 2Adjust lookback period
PS> .\get-currentSVCAccounts.ps1 -n 90 -APIKey eyJ...
Limits results to service accounts that logged on within the past 90 days.
