Segmentation Server Scripts

PowerShell Community Segment Server

Scripts for Segmentation Server administration — exporting audit logs, filtering trust server WinRM logs, adding outbound firewall rules to GPOs, and a lightweight single-asset break glass.

Intended run location Most scripts in this section are designed to run directly on a Segment Server or from a machine with PowerShell remoting access to one. The breakglass-single script must run on a machine that can WinRM to the target asset.

Get-AuditLogByTimeRange.ps1

PowerShellAudit Export
🔗 View on GitHub

Synopsis

Prompts for a start and end time, then pages through the Zero Networks audit log API and exports all matching events to a CSV file in the user's profile directory.

Prerequisites

RequirementDetails
API KeySet $APIKey in the script (the variable is commented out — uncomment and populate, or use your preferred secrets method).
AuditTypes.jsonOptional — the script includes an inline enum for audit type IDs. The JSON reference file is available in the upstream Community repo at .github/modules/ps/AuditTypes.json.
Example 1Export May 2024 audit log to CSV
PS> $APIKey = 'eyJ...'
.\Get-AuditLogByTimeRange.ps1
Prompts for start and end times in ISO 8601 format (e.g. 2024-05-01T00:00:00Z). Exports results to %USERPROFILE%\Audit Log-<start>-to-<end>.csv using 400-record pages and cursor-based pagination.

znlog-filter.ps1

PowerShellLog Analysis
🔗 View on GitHub

Synopsis

Filters Zero Networks WinRM trust server logs (including archived zips) by a specific asset ID, extracting all matching log lines to a single output file for analysis.

Interactive Prompts (with defaults)

PromptDefaultDescription
AssetIDa:a:XYZabc12Zero Networks internal asset ID (find in portal URL)
Log Folder pathC:\Program Files\Zero Networks\LogsFolder containing trust-winrm.log and zips
Days to look back2How many days of zip archives to include
Output Path%USERPROFILE%\zn-tmpDirectory for extracted files and output
Output file<output-path>\trust-winrm_filtered.txtFile to write matching log lines to
Example 1Filter logs for a specific asset (accept all defaults)
PS> .\znlog-filter.ps1
Prompts interactively for each value. Press Enter to accept the bracketed default. Extracts recent zip archives, copies the current log, then filters all files for lines matching assetId=<your-id>.

Add-ZNOutboundRulesProtectGPO.ps1

PowerShellGPOActive Directory
🔗 View on GitHub

Synopsis

Adds outbound Windows Firewall allow rules to the Zero Networks Protect GPO (ZeroNetworksProtect-DoNotModify) for Domain Controller and DNS/DHCP traffic.

Warning This script modifies Group Policy. Run it on a domain controller or from a machine with GPMC access. The target GPO name defaults to ZeroNetworksProtect-DoNotModify and must already exist. If multiple protect GPOs exist the script will prompt for clarification.

Rules Added

Rule NameDirectionPortsPurpose
ZNAccessOut-ADDC (TCP)Outbound53, 88, 135, 389, 445, 464, 636, 3268–3269, 49152–65535AD domain controller TCP traffic
ZNAccessOut-ADDC (UDP)Outbound53, 67, 88, 123, 138, 389, 464AD domain controller UDP traffic
ZNAccessOut-DNS-DHCP (TCP)Outbound53, 67–68DNS and DHCP TCP
ZNAccessOut-DNS-DHCP (UDP)Outbound53, 67–68DNS and DHCP UDP
ZNAccessOut-ICMPOutboundICMP (protocol 1)Ping
Example 1Add outbound rules to the Protect GPO
PS> .\Add-ZNOutboundRulesProtectGPO.ps1
Discovers all DC IP addresses in the forest, locates the Protect GPO, and adds the outbound firewall rules. If the GPO name cannot be resolved automatically, the script prompts for the GPO name.

breakglass-single.ps1

PowerShellEmergency
🔗 View on GitHub

Synopsis

A minimal single-asset break glass script. Uses PowerShell Remoting (Kerberos) to add Windows Firewall rules allowing all inbound and outbound traffic on a named target asset.

Warning This script opens all inbound and outbound traffic on the target. It is a quick-recovery tool for scenarios where the main Break Glass scripts are not available. See the BreakGlass Reference for the full pre-installed scripts.

Configuration (edit at top of script)

VariableDescription
$AssetFQDNFQDN of the target asset (default: test.computer.com — must be changed)
$CredentialPrompts for credentials at runtime via Get-Credential
Uncomment the -localport 3389 variant and comment out the "allow all" rule to restrict break glass to RDP only.
