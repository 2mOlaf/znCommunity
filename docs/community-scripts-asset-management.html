Asset Management Scripts

PowerShell Community ZN API

Community scripts for managing assets throughout their lifecycle in Zero Networks Segment — from enrollment and learning through protection, plus group management, auditing, label import, OT/IoT asset creation, and cluster pinning.

Community scripts — not part of ZNTools or the PSGallery module These scripts are standalone utilities in the community repository under Segment/Segment/Asset Management/. Most require a Zero Networks API key. Review and configure each script before running in production.

Prerequisites

RequirementDetails
API KeyMost scripts require a read/write Zero Networks API key set in the script or passed as a parameter.
ZeroNetworks moduleSome scripts auto-install Install-Module ZeroNetworks if not present. Others use Invoke-RestMethod directly.
PowerShell versionPowerShell 5.1+ for most scripts; PowerShell 7.0+ required for Pin-AssetsToClusters and New-OtAsset.
ImportExcel moduleRequired for Import-AssetLabels. Install with Install-Module ImportExcel.

Add-AssetsToLearning.ps1

PowerShellAsset Lifecycle
🔗 View on GitHub

Synopsis

Reads a list of asset hostnames from a text file, resolves them to Zero Networks asset IDs, and queues them for network learning.

Configuration (edit at top of script)

VariableDescription
$apiTokenZero Networks API key
$filePath to a plain-text file with one hostname per line (e.g. C:\temp\hosts.txt)
$adDomainAD domain to append to each hostname to form an FQDN
$daysToLearnNumber of learning days (default: 30)
$maintenanceWindowIdOptional maintenance window ID (format: e:m:xxxxxxx)
Example 1Run the script after configuring variables
PS> .\Add-AssetsToLearning.ps1
Reads hostnames from the configured file, resolves each to a ZN asset ID using Search-ZNAsset, then POSTs to /assets/actions/queue with the configured learning duration and optional maintenance window.

Move-ProtectToLearning.ps1

PowerShellAsset Lifecycle
🔗 View on GitHub

Synopsis

Fetches all currently protected assets, unprotects them, then immediately re-queues them for a 30-day learning cycle.

Warning This removes protection from all segmented assets. Use only when intentionally rolling back to learning across the board.
Example 1Unprotect all and re-queue for learning
PS> $APIKey = 'eyJ...'
.\Move-ProtectToLearning.ps1
Pages through all protected assets (400 at a time), collects their IDs, calls POST /assets/actions/unprotect, then POST /assets/actions/queue with queueDays=30.

Create-LearnWithBlocks.ps1

PowerShellGroupsAsset Lifecycle
🔗 View on GitHub

Synopsis

Creates (or updates) a custom group named AllLearningWithBlocks and populates it with every asset currently in Learning-with-Blocks mode (protection states 15–18).

Idempotent — safe to run repeatedly. The script checks for the group before creating it, and only adds members that are currently in a blocks-mode learning state.

create-GroupEnv.ps1

PowerShellGroups
🔗 View on GitHub

Synopsis

Reads a CSV of devices with Name, Fully qualified domain name, and Environment columns. For each unique environment value, creates a custom group (if it doesn't exist), then adds the matching assets as members.

Parameters

-CsvFilePath

Full path to the input CSV. Required columns: Name, Fully qualified domain name, Environment. Environment may be blank or comma-separated for multi-environment devices.

Required:True
-BaseApiUrl

Zero Networks API base URL, e.g. https://portal.zeronetworks.com/api/v1.

Required:True
-ApiKey

Zero Networks API key.

Required:True
Example 1Create environment groups from a device CSV
PS> .\create-GroupEnv.ps1 -CsvFilePath "C:\devices.csv" -BaseApiUrl "https://portal.zeronetworks.com/api/v1" -ApiKey eyJ... -Verbose

New-OtAsset.ps1

PowerShell 7+OT / IoT
🔗 View on GitHub

Synopsis

Creates one or more OT/IoT assets individually (by parameter) or in bulk (from CSV). Reads the API URL from the JWT token. Supports dry-run mode.

Parameters

-CsvFilePath

Path to a CSV exported from the companion Excel workbook. When provided, -ip and -name are not needed.

Required:Optional (required without ip/name)
-ApiKey

API key. Falls back to $Env:ZN_API_KEY.

Required:Optional
-ip

IPv4 address of the OT/IoT device.

Required:Optional (required without CsvFilePath)
-name

Display name for the asset in the portal.

Required:Optional (required without CsvFilePath)
-DryRun

Preview what would be sent to the API without making any changes.

Type:Switch
Example 1Create a single OT asset
PS> .\New-OtAsset.ps1 -ip 192.168.10.5 -name PLC-01
Example 2Bulk import from CSV (dry run)
PS> .\New-OtAsset.ps1 -CsvFilePath .\devices.csv -DryRun

Pin-AssetsToClusters.ps1

PowerShell 7+Deployment Clusters
🔗 View on GitHub

Synopsis

Pins or unpins assets to deployment clusters. Supports single-asset operations by asset ID or OU path, bulk operations via CSV, dry-run preview, and cluster listing.

Parameter Sets

SetRequired ParametersUse Case
ByAssetId-ApiKey, -AssetId, -DeploymentClusterIdPin/unpin a single asset
ByOuPath-ApiKey, -OUPath, -DeploymentClusterIdPin/unpin all assets in an OU
ByCsvPath-ApiKey, -CsvPathBulk pin/unpin from CSV file
ListDeploymentClusters-ApiKey, -ListDeploymentClustersList all available clusters
ExportCsvTemplate-ExportCsvTemplateGenerate a blank CSV template
Example 1Pin a single asset to a cluster
PS> .\Pin-AssetsToClusters.ps1 -ApiKey eyJ... -AssetId a:a:qvI6tVtn -DeploymentClusterId C:d:00fd409f
Example 2Preview bulk CSV changes (dry run)
PS> .\Pin-AssetsToClusters.ps1 -ApiKey eyJ... -CsvPath .\assets.csv -DryRun
Example 3Unpin all assets in an OU
PS> .\Pin-AssetsToClusters.ps1 -ApiKey eyJ... -OUPath "OU=Computers,DC=domain,DC=com" -DeploymentClusterId C:d:00fd409f -Unpin
