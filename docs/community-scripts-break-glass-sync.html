Break Glass Sync Module

PowerShell Community Module Emergency Prep

A PowerShell module that copies the Zero Networks BreakGlass\ directory from a Segment Server to a secondary destination server — ensuring break glass scripts and the segmentedAssets.json file are available from a backup location.

Purpose The pre-installed BreakGlass scripts on your Segment Server require segmentedAssets.json to be current. This module enables you to replicate the entire BreakGlass directory to a standby server so it can serve as a fallback run location if the primary Segment Server is unavailable.

Prerequisites

RequirementDetails
PSRemotingMust be enabled on both the Segment Server and destination server (Enable-PSRemoting -Force)
Inbound WinRM allow ruleThe machine running this script must have an inbound allow rule permitting WinRM to both servers (no MFA required on that rule)
Account permissionsThe account used must be a local administrator on both servers and have write access to the destination directory. May need to run Set-PSSessionConfiguration -Name Microsoft.PowerShell -ShowSecurityDescriptorUI -Force on each server to grant PSRemoting permissions.
Disk spaceEnough temporary space on the machine running the script for a zip of the BreakGlass directory

Sync-BreakGlassDirectory

PowerShellPSModule

Synopsis

Connects to the Segment Server via PSSession, compresses C:\Program Files\Zero Networks\BreakGlass\ to a zip, copies it locally, then copies and extracts it to a remote directory on the destination (BreakGlass) server.

How It Works

  1. Opens a PSSession to the Segment Server (source).
  2. Compresses the BreakGlass directory to BreakGlass.zip on the Segment Server.
  3. Copies BreakGlass.zip from the Segment Server to the local machine running the script.
  4. Closes the Segment Server PSSession.
  5. Opens a PSSession to the BreakGlass Server (destination).
  6. Copies the local BreakGlass.zip to the specified RemoteDirectory on the destination.
  7. Extracts the zip on the destination server.
  8. Closes the PSSession and removes the local BreakGlass.zip.

Parameters

-SegmentServer

Short hostname of the source Segment Server (e.g. znserver). Do not include the domain suffix.

Required:True
-BreakGlassServer

Short hostname of the destination server to copy the BreakGlass directory to.

Required:True
-RemoteDirectory

Path on the destination server where the BreakGlass directory will be copied. The account used must have write access to this path.

Example:C:\Users\Public\ZNBreakGlassFiles
Required:True
-Credential

A PSCredential object for authenticating to both servers. Use Get-Credential to create one interactively. Mutually exclusive with -Username / -Password.

Required:Optional (use with -Credential or -Username/-Password)
-Username / -Password

Plaintext username and password alternative to providing a PSCredential object. Can also be set via $ENV:segmentServer, $ENV:breakGlassServer, etc. for automation.

Required:Optional

Examples

Example 1Sync using explicit credentials
PS> Import-Module .\sync_breakglass_directory.psd1
Sync-BreakGlassDirectory -Username adminUser -Password adminPwd `
  -BreakGlassServer destinationServer -SegmentServer znSegmentServer `
  -RemoteDirectory "C:\Users\Public\ZNBreakGlassFiles"
Example 2Sync using Get-Credential (interactive)
PS> Import-Module .\sync_breakglass_directory.psd1
Sync-BreakGlassDirectory -Credential (Get-Credential) `
  -BreakGlassServer destinationServer -SegmentServer znSegmentServer `
  -RemoteDirectory "C:\Users\Public\ZNBreakGlassFiles"
Example 3Sync using environment variables (automation)
PS> $ENV:segmentServer = "ZnSegmentServer1"
$ENV:breakGlassServer = "BackupServer"
$ENV:adminUser = "domain\admin"
$ENV:adminPwd = "password"
Import-Module .\sync_breakglass_directory.psd1
Sync-BreakGlassDirectory -RemoteDirectory "C:\ZNBackup"

Scheduling

For best results, schedule this module to run regularly (e.g. via Task Scheduler or a CI pipeline) so the segmentedAssets.json on the backup server stays current. The asset list is updated continuously by the Segment Server as assets are added and removed.
