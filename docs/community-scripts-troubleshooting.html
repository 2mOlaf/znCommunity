ZNConnectivityTest.ps1

PowerShellConnectivity
🔗 View on GitHub

Synopsis

Tests TCP connectivity and DNS resolution to all required Zero Networks cloud endpoints from the machine running the script. Reports any failures.

Endpoints Tested

HostnamePortPurpose
monitor.zeronetworks.com443Telemetry / metrics
portal.zeronetworks.com443Management portal
download.zeronetworks.com443Package downloads
access.zeronetworks.com443Access control
2fa.zeronetworks.com443MFA push
cloud-prod-v2.zeronetworks.com443Cloud backend
register-prod.zeronetworks.com443Registration
cloud-connector.zeronetworks.com443Cloud Connector
connect-backend.zeronetworks.com443Connect backend
connect.zeronetworks.com443Connect service
jamf-connector.zeronetworks.com443Jamf integration
register-cloud-connector.zeronetworks.com443CC registration
Example 1Run connectivity test
PS> .\ZNConnectivityTest.ps1
Tests each endpoint with Test-NetConnection and Resolve-DnsName. Outputs failures immediately; prints "All connections succeeded" if everything passes. Returns a table of failed endpoints at the end.

Network Port Connectivity Check.ps1

PowerShellConnectivity
🔗 View on GitHub

Synopsis

Tests TCP and UDP port connectivity against the required ports listed in the Zero Networks Deployment Guide, scoped to a specific machine profile. Results are color-coded in the console.

Parameters

-machineProfile

The type of machine to test connectivity for. Determines which set of ports to validate.

Accepted values:Client, Trust Server
Required:True

Example 1Test connectivity for a client machine
PS> .\"Network Port Connectivity Check.ps1" -machineProfile Client
Example 2Test connectivity from a Trust Server
PS> .\"Network Port Connectivity Check.ps1" -machineProfile "Trust Server"

checkAdmin.ps1

PowerShellGPO Validation
🔗 View on GitHub

Synopsis

Checks whether ZNRemoteManagementGroup is a member of the local Administrators group. If not, identifies any GPOs with Restricted Groups settings that may be removing it, and checks their content.

Run this script on an asset that is unexpectedly losing its ZNRemoteManagementGroup admin membership to identify conflicting GPOs.
Example 1Check admin group membership and GPO conflicts
PS> .\checkAdmin.ps1
If ZNRemoteManagementGroup is present, reports success. If missing, runs gpresult /r, identifies Restricted Groups GPOs, reads their SYSVOL templates, and reports whether each GPO configures the Administrators group.

CollectSMBDetails.ps1

PowerShellETW Tracing
🔗 View on GitHub

Synopsis

Starts an ETW (Event Tracing for Windows) session to capture Zero Networks WPP trace events and SMB client events, writing them to a rotating .etl file for diagnostic analysis.

Configuration

VariableDefaultDescription
$etwSessionNameETWWppTestSessionETW session name
$logPathC:\WPPLogs_<hostname>Output directory for trace files
$rolloverInterval24 (hours)Log rotation interval
The output .etl file can be opened with Windows Performance Analyzer (WPA) or converted with tracerpt. Share with Zero Networks support when troubleshooting SMB-related connectivity issues.
